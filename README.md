# 矩阵复习

判断练习、计算题详解与知识点整理。

打开index.html，或在GitHub Pages发布后访问网页。题目附答案与解析，LaTeX和字体随网页提供。

每位读者从空白练习进度开始。进度仅保存在自己的浏览器，可导出JSON备份；不同设备不会自动同步。本分享版不含原使用者的75题历史作答、考后个人作答对照、课本PDF、课堂照片或私有Git历史。

书稿引用保留章节与页码。考试回忆中的缺失数值、记忆分值、自拟演示分别标明。

维护者在源项目中修改题库，通过发布工具生成并同步分享版。main分支更新后，GitHub Pages自动更新网页，网址保持不变。
访问者刷新页面即可读取更新；同一浏览器中的已有练习进度按题号保留。
